Preparación

Listo para tu primera inmersión.

Windows / PCVR

  1. Descarga y extrae el ZIP completo en una carpeta.
  2. Abre OceanVR-1.0.0-demo.exe. Mantén el archivo PCK y la DLL incluidos en esa misma carpeta.
  3. Para PCVR, conecta primero el visor y prepara tu entorno OpenXR. Sin visor, el juego entra en modo escritorio.
  4. Selecciona el modo educativo para aprender con indicaciones durante la partida.

Meta Quest 2

  1. Prepara el visor para instalar aplicaciones mediante SideQuest.
  2. Conéctalo al PC por USB y acepta la autorización de depuración dentro del visor.
  3. Instala el APK descargado mediante SideQuest.
  4. Abre Ocean VR desde las aplicaciones de orígenes desconocidos del visor.
¿Ya tienes una versión de prueba? Este APK usa firma de presentación. Si la instalación indica una firma incompatible, no desinstales la versión anterior sin respaldar tus fotos y progreso. Solicita la migración al responsable de la demo.
Antes de empezar

Controles y detalles.

¿Cómo se juega?

PC: apunta con el ratón y mantén clic izquierdo para interactuar. Usa WASD para moverte y P para pausar. La cámara se suelta con clic derecho.
VR con mandos: apunta y usa el gatillo; suelta la cámara con grip. Puedes pulsar los botones de la cabina directamente.
Sin mandos: usa el seguimiento de manos del visor para interactuar con los controles. Pausa y Reiniciar están en la cabina.

¿Qué incluye esta entrega?

La demo 1.0 incluye los modos educativo y arcade, fotografías, almanaque, ajustes, pausa y reinicio. La visualización de modelos del almanaque ocurre dentro del juego; no incluye passthrough de realidad aumentada.

Créditos y archivos verificables

Esta es una demo para presentación y evaluación. Los recursos de terceros mantienen sus atribuciones; la descarga no concede derechos para reutilizarlos o comercializarlos. Consulta los créditos, las notas de la entrega y las sumas SHA256.
